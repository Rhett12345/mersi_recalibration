## 历史结果来源问题

同一输入日的历史 `cali_result_correct` CSV 与当前未优化 v3 重跑之间已有差异，最大系数绝对差为 0.274588。该差异在优化前就存在，不能归因于本轮优化，也不能在缺少原始版本说明时宣称已复现全部历史结果。

审查发现旧后处理会添加带噪邻近日伪样本、把斜率拉向固定参考值；旧误差统计还会重复减去 SV 并手工增加不同常数偏移；部分插值把异常观测替换成邻近日伪值。这些模块只作历史快照，本轮新实验均未执行。需要先追溯历史 CSV、图件对应的拟合版本和后处理，才能决定旧论文图表能否继续使用。
