# FY-3D / FY-3F 固定系数再定标验证

本实验不进行逐日插值。以下指标全部来自未参与对应系数拟合的观测日期；前后使用相同有效样本。结果表示相对光谱转换后的 MODIS 参考观测的一致性，不等同于绝对辐射真值精度。

## 方法与实现

- 统一配置入口保留独立的 FY-3D/MERSI-II/Aqua 与 FY-3F/MERSI-III/Terra 身份、QA 规则、原生系数及光谱响应。原始生产代码和历史结果未覆盖。
- FY-3D 按年拟合固定系数，每年最后 25% 有效日期留出验证；FY-3F 使用 2025-01-22 更新后的固定系数分段，延续既有时间划分。训练阶段两遍 OLS、2σ 筛选，验证阶段不按残差剔除样本。
- 匹配阈值保持不变：1 km、600 s、VZA <30°、观测余弦比差 <0.01、SZA <75°、3×3 B3 CV ≤2%。QA、波段有效域和光谱训练域限制保持独立记录。
- 使用实际 MODTRAN 光谱和各平台 SRF 分别卷积，按大气廓线划分光谱转换训练/测试。模拟光谱不计入观测样本。
- 新增 MAE、验证集回归斜率/截距/R²、按日期成对 bootstrap 的改善区间，以及完整样本的密度与残差计数。统一绘图模块输出 600 dpi PNG、PDF、SVG。
- 缓存读取改为预分配数组，避免先保存全部分片再拼接造成的额外内存占用；原有重复像元选择顺序保持不变。

## 独立日期验证指标

Ref* 为辐亮度等效反射率百分数，尚未乘 d²/cos(SZA)。Bias、RMSE、MAE 的绝对单位为百分点（pp），相对 Bias 单位为 %。TOA 指标在各平台 metrics.csv 的 TOA 行单独给出。改善百分比 = 100×(1−再定标后误差/再定标前误差)，负数表示退化。

## 结论与不改善的情况

FY-3F 七个波段的固定系数再定标均降低了本次独立日期 RMSE；B1–B4 的相对偏差明显收敛。FY-3D 的年度固定系数汇总结果中，B4 仅改善约 2.2%，95% 日期 bootstrap 区间跨零，且相对 Bias 的绝对值略增，因此不能认定该波段稳定改善。其原始相对 Bias 仅约 −0.275%、RMSE 约 0.866 pp，原有定标较好，改善空间有限；但跨年正负误差可能抵消，且光谱转换、季节与观测几何仍影响结果，不能将低总体 Bias 当作原定标在全部条件下准确的证明。

FY-3D 各年度也存在真实退化（RMSE 改善率为负）：

| 年度 | 波段 | RMSE 改善 (%) |
|---|---|---:|
| 2018 | B01 | -15.48 |
| 2018 | B02 | -11.81 |
| 2020 | B02 | -0.95 |
| 2018 | B04 | -24.10 |
| 2019 | B04 | -7.63 |

跨多年只拟合一套固定系数的压力测试中，B1–B7 的 RMSE 改善率依次为：-63.4%, -29.7%, 0.6%, 17.9%, 1.2%, -54.8%, -154.5%。这说明不能把年度固定系数的改善推广成多年通用常数。该压力测试的时间划分不同，不能直接与年度汇总表做同样本排名。

## 科学限制

1. 日期留出保证系数拟合与验证分离；历史方法开发已接触部分日期，因此不是完全盲测。按日期 bootstrap 的区间以已拟合系数为条件，不包含全部参考传感器、光谱转换和几何系统误差。
2. FY-3D 按年固定系数的结果不代表一套常数能覆盖整个多年记录。跨年单一系数的压力测试单列于 fy3d_matched/calibration_summary.json，不能与主表混称。
3. 数据集中在近极地同轨观测条件，尚不能证明全球适用性、长期稳定性或下游云检测精度提升。SZA 分箱还受表面和季节混杂影响。
4. 1.38 µm 弱信号波段的相对误差对参考均值敏感；需同时看绝对误差、相对误差和负值数量。改善有限或区间跨零的波段不得表述为已稳定改善。
5. 仅评估现有科学流程支持的 B1–B7 反射太阳波段。其余波段未通过本实验验证。FY-3D 历史归档系数与原始 v3 重算的来源差异仍存在，本实验不为那些历史后处理结果背书。
